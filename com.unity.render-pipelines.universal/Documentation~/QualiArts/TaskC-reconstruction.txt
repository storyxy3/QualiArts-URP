Interpretation of remaining native flags
  same = normalized instructions match. [layout] = tool reports matching semantic tokens with different layout.
  [semantic] is retained verbatim even when manual review identifies an inlining, trampoline, or scheduling difference.
  not done = some native entry points are missing/re-signed or the type has no reconstructed implementation.
  only-in-game also includes compiler-generated local functions, stripped generic instantiations, and empty constructors.
  ConstantBuffer/ConstantBufferSingleton and VolumeParameter generic source already exists; absent native specializations
  are not evidence that those generic methods need replacement stubs. Their missing instantiations remain unverified.
  RTHandle.op_Implicit overloads share argument signatures but differ in return types; the comparison tool can pair them ambiguously.
  Empty constructor aliases (e.g. DebugUIHandlerWidget/Object) and RenderGraph lambda/metadata layout cause additional flags.
  CoreUtils.CreateCubeMesh, ShadowUtils.ExtractDirectionalLightMatrix, lighting debug post-process gate, and
  DrawObjectsPass.ExecutePass matched after restoring actual behavioral differences.
  UniversalRenderer constructor differs at an empty RenderGraphFrameResources/Object constructor alias.
  InitializeRenderingData has a renderingModeActual inlining/call-token difference; the game decompilation has the same check.
  FogUtility.UpdateProperties, MipChainBuffer and RenderingBridge retain compiler scheduling/bounds-check/inlining flags.
  MipChainBuffer local functions are implemented as |36_0/|36_1; game names are |39_0/|39_1, so raw inventory still lists them.
  ConvolutionBlur..cctor includes a game metadata trampoline that the normalizer cannot resolve to ToArray<int>.
  SubWorldUtility.UpdateReflectionStencilState retains conditional constant-selection scheduling after two formulations.
  Task B DeferredLights/planar flags are documented in TaskB-reconstruction.txt and were not altered here.
  FogUtility has no deferred-draw method in the supplied assembly dump; its retained samplers/dictionaries are fields only.
